# 講師推介名單 — 使用說明

這個網站只有兩個部分：

- `index.html`：前台頁面，純展示，沒有任何編輯功能。
- `data/speakers.json`：所有講師與課程資料都在這裡。**你要改資料，只需要改這一個檔案。**

`index.html` 打開時會自動讀取同一個資料夾裡的 `data/speakers.json`，
所以你只要把這個檔案換成新的內容、存檔（或在GitHub上直接編輯後commit），
前台畫面下次打開就會自動變成新的內容，不需要碰 `index.html`。

---

## 怎麼新增一位講師

打開 `data/speakers.json`，會看到一個用 `[` `]` 包起來的清單，裡面一位講師是一段 `{` `}`。
複製下面這個範本，貼在清單最後一位講師的 `}` 後面（記得中間要加一個逗號 `,`），
再把內容換成新講師的資料就好：

```json
{
  "姓名": "講師姓名",
  "簡歷": "講師簡歷／身份，一段文字",
  "地點": "台澎金馬（需車馬）",
  "講題方向": ["關鍵字1", "關鍵字2"],
  "適合對象": "適合的系所或對象說明",
  "鐘點費": "",
  "課程": [
    {
      "課程名稱": "課程標題",
      "時長": "120 分鐘",
      "課綱": [
        { "時間": "0:00–0:20", "內容": "第一段內容" },
        { "時間": "0:20–0:40", "內容": "第二段內容" },
        { "時間": "1:40–2:00", "內容": "Q&A", "類型": "qa" }
      ],
      "學員收穫": [
        "收穫一",
        "收穫二"
      ]
    }
  ]
}
```

**幾個容易出錯的地方：**

- 每一行的中文字外面要有引號 `"..."`，不能漏掉。
- 每一項後面除了「這個講師/課程/欄位的最後一項」以外，都要加逗號 `,`。
- `"類型": "qa"` 只有Q&A那一行才需要加，其他行不用寫這個欄位。
- 如果不確定改得對不對，可以把整個檔案內容貼到 [jsonlint.com](https://jsonlint.com) 檢查有沒有格式錯誤，
  它會告訴你哪一行有問題。

## 怎麼刪除一位講師 / 一堂課

直接把對應的整段 `{ ... }`（含前後的大括號）刪掉即可。
如果刪的不是清單最後一項，記得確認前一項結尾有逗號、最後一項結尾不要留逗號。

## 怎麼調整課程順序

把整段課程的 `{ ... }` 剪下來，貼到 `"課程": [` 陣列裡你想要的位置即可，順序就是畫面上顯示的順序。
講師的順序不用手動排，前台會自動依照姓名筆劃排序。

## 上傳到 GitHub Pages

1. 到 [github.com](https://github.com) 開一個新的 repository（公開 public，才能用免費的GitHub Pages）。
2. 把這個資料夾裡的 `index.html` 和 `data/` 資料夾整個上傳進去（可以直接在網頁上拖曳上傳）。
3. 進 repository 的 **Settings > Pages**，Source 選 `main` 分支、資料夾選 `/ (root)`，儲存。
4. 等一兩分鐘，GitHub會給你一個網址（通常長得像 `https://你的帳號.github.io/repo名稱/`），
   打開就是正式的前台頁面。
5. 之後要更新資料，就回到repository裡點開 `data/speakers.json`，
   按右上角的鉛筆圖示編輯，改完按 **Commit changes**，
   等一兩分鐘網站就會自動更新，不用重新上傳整個網站。

## 關於公開性

免費版GitHub Pages必須用「公開」repository才能運作，代表 `data/speakers.json` 這個檔案
理論上任何人都能透過網址直接看到（不只是前台頁面顯示的內容）。

`"鐘點費"` 欄位目前預設留白，前台會顯示「鐘點費：」這行文字方便你之後直接在JSON裡補上數字。
如果之後改變主意、不想讓鐘點費公開，記得把這個欄位從JSON裡拿掉，或改用其他不公開的地方記錄。

## 本機預覽時要注意

如果你直接在自己電腦上用瀏覽器打開 `index.html`（不是透過網址），
有些瀏覽器（尤其Chrome）基於安全性考量，會擋掉它讀取旁邊 `data/speakers.json` 的動作，
畫面會顯示「名單載入失敗」。

這是正常的，不是壞掉——**上傳到GitHub Pages後用網址打開就會正常**。
如果想在上傳前先在本機測試，最簡單的方法是在這個資料夾裡開一個終端機，執行：

```
python3 -m http.server 8000
```

然後瀏覽器打開 `http://localhost:8000` 即可看到跟正式上線一樣的畫面。
